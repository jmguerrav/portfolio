00Igni · how I think

Igni: how my mind works, written down.

Igni is the agentic architecture I work inside: a knowledge graph for what I know, written rules for how I work, and a harness that loads both into every LLM agent before it touches a file, whichever model it is, my own included. When an agent gets something wrong, the fix becomes a lesson; a lesson that repeats becomes a rule. Less an app than a way of working the agents can read.

  1. a mistake
  2. a lesson
  3. it repeats
  4. a rule
  5. every agent, next session
  1. Each file becomes nodes and the links between them. An agent asks a question in plain words and gets back the few files that answer it, with the path to open, instead of reading the whole tree.
  2. Rules say what never to do and why. Skills are step-by-step recipes for a kind of job. Hooks run on their own at the start and end of a session, so nothing depends on the agent remembering.
  3. A claim is a line in a shared file: who, which path, since when. A second agent that asks for the same path is refused. Every change ends with an entry in the ledger, so tomorrow’s session can read what today’s did.
  4. The harness routes each request to the right skill, gives the model its tools and checks the result before it counts. A capability isn’t done until it passes the same test gauntlet every time.
  5. One script runs every step in order and writes a one-line status for each. A checker that can’t run is reported as broken, not as clean, and the morning brief says what needs me.
  6. Each lesson records what happened, why and what to do instead. Every session opens with the latest ones, so a mistake made on Monday by one model isn’t repeated on Tuesday by another.
  7. It reads the same status files the agents write. Green checks make it calm; a failed step or a stale claim changes its expression, so I see trouble before I read a log.

06Own model

My own model, running offline.

An open model on my laptop inside Raszagal, a harness I wrote. Given a written brief, it picks my process-diagram skill and returns the finished CAD drawing on its own: 119 s the first time.

Raszagal routes each request to a skill, retrieves from my knowledge graph, and verifies answers by running them instead of judging them: code pass rate went from 72 to 89 % on that change alone. Anything that came in through web or mail is tainted and cannot run code until I approve it.
